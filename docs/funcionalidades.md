## Funcionalidades

O site da Rosane Modas possui as seguintes funcionalidades previstas:

- Navegação pelo menu principal;
- Visualização das categorias de produtos;
- Visualização dos produtos com imagem, nome e preço;
- Botão para visualizar todos os produtos;
- Botão para acessar a área de compras;
- Busca de produtos por nome;
- Adição e remoção de produtos do carrinho;
- Sistema de produtos favoritos;
- Links para as redes sociais da loja;
- Página com informações sobre a Rosane Modas;
- Página de contato;
- Layout responsivo para computadores, tablets e celulares.
