# Arquivos detalhados

## Estrutura atual

```text
readme.md/
├── README.md
├── _config.yml
└── docs/
    ├── arquivos-detalhados.md
    └── funcionalidades.md
```

## Descrição

- **README.md:** página inicial com as informações principais do projeto.
- **_config.yml:** arquivo de configuração do GitHub Pages.
- **docs/:** pasta que guarda as páginas complementares.
- **docs/funcionalidades.md:** explica as funcionalidades do site.
- **docs/arquivos-detalhados.md:** explica a estrutura e os arquivos do projeto.

A estrutura deverá ser atualizada quando novos arquivos forem adicionados ao projeto.
